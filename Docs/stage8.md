## 2. Грабли этапа — читать перед правками

1. **`next.config` `images: { unoptimized: true }`** — автооптимизация Next
   выключена. Значит любые новые картинки нужно класть **сразу в WebP** (готовыми),
   `next/image` их не сожмёт. Галерея флота — через sharp-пайплайн в админке.
2. **Логотип 2ГИС — оригинальный SVG**, многоцветный. В футере ему НЕ задаём
   `color` (как Google Maps), иначе бессмысленно.
3. **Dev-сервер и новые вложенные маршруты:** после создания новой папки
   `app/.../page.tsx` dev иногда отдаёт 404 по залипшему watcher (особенно после
   `npm run build`, который трогает `.next`). Лечение — **перезапуск `npm run dev`**.
   Прод-сборка при этом маршрут видит нормально (проверено).
4. **`components/hero/` удалён целиком** — если что-то захочет его импортнуть,
   его нет; актуальный Hero — `components/nevsky/hero.tsx`.
5. **Лендинги: контент только в `lib/landings.ts`.** Каркас общий
   (`landing-page.tsx`). Метаданные — через `buildLandingMetadata`. Не дублировать
   логику в `page.tsx` (они тонкие).
6. **`sitemap.xml` не редактируется руками** — генерируется из массива `landings`.
   Добавил лендинг в массив → он в sitemap автоматически.
7. **Press-эффект держится на `group-active`** (`:active` всплывает от ссылки к
   `.reveal`-группе). Внутренняя обёртка со своим `transition-transform` — не
   убирать, иначе scale поедет на 1s reveal-транзишене.
8. **Апострофы в EN-текстах лендингов:** строки в одинарных кавычках — внутри
   использовать типографские `’`/`—`, не прямой `'` (иначе оборвёт строку). В
   текущих текстах прямых апострофов нет.

## 4. Как продолжать

- Локальная БД `river2_dev`, `npm run dev` → localhost:3000. Проверка типов —
  `npx tsc --noEmit`; полная сборка — `npm run build` (при странных ошибках типов
  из `.next` — сначала `rm -rf .next .next-build`; после build перезапустить dev,
  если новые маршруты 404-ят).
- **Деплой (я сам, только с одобрения заказчика):**
  ```bash
  git push origin main
  ssh -i ~/.ssh/claude-deploy-river2 root@85.198.68.244 'bash /root/dno/scripts/deploy.sh'
  ```
  `deploy.sh`: pull → `npm ci` → `prisma migrate deploy` → сборка в `.next-build` →
  бесшовная подмена → pm2 reload → проверка 200 → авто-откат. Миграций в этом окне
  не было (только код и контент).
- **Добавить новый лендинг:** объект в `lib/landings.ts` (RU+EN) → добавить в
  массив `landings` → создать `app/<slugRu>/page.tsx` и `app/en/<slugEn>/page.tsx`
  (копии существующих, поменять `getLanding('key')` и `lang`) → при желании
  привязать плитку (`href` в `experiences` в `lib/i18n.ts`). sitemap подхватит сам.
- **SEO-выводы проверяются curl’ом на боевом:** статус лендингов (200),
  `/sitemap.xml` (`grep -c "<url>"`), JSON-LD в HTML (`"@type":"..."`), плитки-ссылки
  на главной. Микроразметка — валидатором Яндекс.Вебмастера и Google Rich Results.

**Выкатка на боевой — только с одобрения заказчика.**
