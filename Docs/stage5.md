## 1. Что сделано в этом этапе

### Подарочные сертификаты — главное окна (`1baedc8`)
Сертификат на прогулку **1 час, не именной** (поля «Для/От» на бланке —
пустые линии для руки). Живёт в том же Next-приложении и менеджерском боте, не
отдельный сервис. Доменное ядро переиспользуется.

- **Модель** `Certificate` (`prisma/schema.prisma`): `number` (уникальный),
  `status` `ISSUED`/`REDEEMED`, `issuedAt/By`, `redeemedAt/By`, `title`.
- **Номер** `DNO` + `YY` + `MM` + `NNNN` (напр. `DNO26070001`). Счётчик NNNN
  **сбрасывается помесячно**, год/месяц петербургские. Генерация атомарная
  (max+1, retry на unique-конфликте) — `lib/certificate/number.ts`,
  `lib/certificate/service.ts` (`issueCertificate`, `findCertificate`,
  `redeemCertificate` — погашение идемпотентно через условный `updateMany`).
- **Рендер бланка** — `lib/certificate/render.ts`: на готовый макет
  (`public/certificate/template.jpg`, 904×1280) накладываются свежие QR
  (`qrcode`) и номер + ссылка. Текст — через **@napi-rs/canvas** (вложенный
  PT Serif, `lib/certificate/fonts/`), НЕ через SVG-текст sharp.
- **Бот** — `lib/certificate/bot.ts` + провод в
  `app/api/telegram/webhook/route.ts`: `/sert` → кнопка «Выпустить» → PNG в
  группу (без подписи, чтобы переслать покупателю) + памятка; `/sert <номер>` →
  карточка статуса + кнопка «Погасить». Также постоянная кнопка «🎟 Сертификат»
  на панели и в меню команд.
- **Страница** `/check/[number]` (`app/check/[number]/`): публично показывает
  «действителен / погашён / не найден»; кнопка «Погасить» — только
  залогиненному менеджеру (server action + `requireAdmin`). QR ведёт на
  `${CERT_CHECK_BASE_URL||https://prokatkaterov.ru}/check/<номер>`.
- **Меню команд** менеджерского бота — `scripts/bot-setup.ts` (разово на
  сервере): `/start`, `/bron`, `/sert`, `/help` во всех скоупах.

### Менеджерский бот: шаг минут 30 (`c5baf80`)
`lib/bot-flow.ts`: кнопки минут в `/bron` и переносе брони теперь `:00`/`:30`
(были `:00/:15/:30/:45`) — как в клиентском боте. Ручной ввод текстом
(`18:15`) по-прежнему принимает любые минуты — не резали.

### Логотип на сайте (`ade8539`, мобильная правка `1fa56ff`)
Заказчик положил `public/logotip/logotip.png` (круглая эмблема на **чёрном
фоне, без альфы**). Вырезал прозрачную версию `public/logotip/logo.png`
(круговая альфа-маска, центр 627/626, r≈598). Эмблема в шапке
(`components/nevsky/site-nav.tsx`) и футере (`site-footer.tsx`), фавикон
`app/icon.png` (Next подхватывает сам). На мобильном (<640px) логотип 24px и
шапка поджата к краю (`px-4`); десктоп не тронут (`sm:` возвращает 40px).

**Отклонённые правки** (заказчик откатил): перенос RU/EN из шапки в мобильное
меню — делать не стал, RU/EN остаётся в верхней строке; на 375px название
бренда ложится в 3 строки — так и оставили осознанно.

## 2. Грабли этапа — читать перед правками

1. **Чистого макета сертификата НЕТ** — только растр с уже впечатанными QR,
   номером и ссылкой. Поэтому в `render.ts` эти три зоны закрываются
   прямоугольником цвета бумаги (`#fefdfb`) и печатается своё. Координаты
   выверены по пикселям (904×1280) детектором цвета — если заменят макет, их
   пересчитать.
2. **librsvg (SVG-текст sharp) корёжит отдельные глифы** — то «0», то «K»
   рисовались комом. Поэтому текст на бланке — через `@napi-rs/canvas`
   (нативный FreeType, вложенный шрифт), не через SVG-`<text>`.
3. **`@napi-rs/canvas` — в `serverExternalPackages`** (`next.config.mjs`):
   `sharp` Next выносит сам, а canvas нет — иначе сборка упакует .node и
   привязка не найдётся в рантайме.
4. **`CERT_CHECK_BASE_URL` — отдельная переменная**, не `NEXT_PUBLIC_SITE_URL`
   (тот локально = `http://localhost:3000`, QR уехал бы в никуда). Дефолт уже
   боевой `https://prokatkaterov.ru` — на сервере доопределять не нужно.
5. **Меню команд Telegram кэшируется на клиенте.** `setMyCommands` выставлен в
   три скоупа (default + all_group_chats + all_private_chats), иначе группа
   показывала старое меню. После деплоя менеджеру полезно тапнуть `/start`.
6. **Правки шапки/футера мобильные — под `sm:`-гейтом.** На широком окне
   разницы нет by design; смотреть в мобильном вьюпорте (<640px). Логотип-
   исходник был без альфы — на тёмной шапке нужен именно `logo.png` (прозрачные
   углы), не `logotip.png`.
7. **`deploy.sh` сам делает `npm ci` + `prisma migrate deploy` до сборки** —
   отдельный шаг миграции не нужен, порядок уже правильный.

  (или `npx tsc --noEmit`) проверяет типы.
- **Деплой я делаю сам** (SSH возвращён), только с одобрения заказчика:
  ```bash
  git push origin main
  ssh -i ~/.ssh/claude-deploy-river2 root@85.198.68.244 'bash /root/dno/scripts/deploy.sh'
  ```

  отдельную папку → подмена без даунтайма → перезапуск pm2 → проверка 200 →
  авто-откат. Новые команды бота регистрируются разово:
  `npx tsx scripts/bot-setup.ts` на сервере.
